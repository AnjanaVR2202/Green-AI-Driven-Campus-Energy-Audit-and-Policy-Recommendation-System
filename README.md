# Green-AI-Driven-Campus-Energy-Audit-and-Policy-Recommendation-System
This project focuses on analyzing campus energy consumption data and identifying unusual patterns in electricity usage using machine learning. The system follows Green AI principles, meaning it aims to achieve efficient results using computationally lightweight models.

The system collects historical energy consumption data from different campus buildings and combines it with contextual features such as time, season, and weather conditions. Machine learning techniques are used to detect anomalies in energy usage, helping identify potential inefficiencies, wastage, or abnormal consumption.

After detecting anomalies, the system evaluates the severity of the issue and generates recommendations that can help reduce energy consumption and improve sustainability practices within the campus.

Key Features
Energy consumption analysis for multiple campus buildings
Anomaly detection using machine learning models
Residual analysis to identify abnormal usage patterns
Recommendation system for energy-saving actions
Green AI approach with optimized computational efficiency
Integration with weather and temporal data
Technologies Used
Python
Pandas & NumPy
Scikit-learn
LightGBM
Flask (for backend deployment)
Machine Learning & Data Analysis
Objective

The main goal of this project is to help campuses reduce energy waste, improve operational efficiency, and support sustainable energy management using AI-driven insights.
